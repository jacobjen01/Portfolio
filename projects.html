My Projects

Moon Rover: Fenris

This project presents the first iteration of the ISRU excavation moon rover Fenris. Fenris I is a fully custom rover built as a bachelor's project. It features a tool for excavation and depositing, a modular design and a sensor tower with LiDAR, 3D camera and a camera ring offering a 360 degree view of its surroundings.

Simultaneous Driving and Manipulation

This project shows bimanual manipulation capabilities integrated with autonomous driving. The robot has been built from the ground up and integrates two UR5e's and a MiR250. A human-machine interface has also been developed.
